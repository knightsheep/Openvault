# OpenVault

> An open vault of technical notes, troubleshooting guides, essays, and reusable knowledge.

一个公开的知识库：技术笔记、故障排查、配置记录、随笔与观点，以及不涉及个人资产信息的经济、金融文章。所有内容使用 Markdown 编写，适合通过 Obsidian 阅读。

## 包含内容

- 技术说明与教程
- 故障排查与解决记录
- 软件或环境配置记录
- 随笔与公开观点
- 不涉及个人资产信息的经济、金融文章

## 如何浏览

- `00-Indexes/` — 入口、索引和 MOC
- `01-Tech/` — 技术类内容（教程、故障排查、配置、笔记）
- `02-Essays/` — 随笔和观点文章
- `03-Economics-and-Finance/` — 公开的经济与金融内容

## 说明

内容主要表达作者的个人理解和经验，不构成专业建议。涉及健康、投资、法律等事项时，请咨询具备资质的专业人士。
